The Linux console is the text screen you get without a graphical session: six virtual consoles on Ctrl+Alt+F1 to F6 (just Alt+F1 ... from another console).

Keyboard layout

For the current session:

$ sudo loadkeys de

Permanently, in /etc/vconsole.conf, which the console-setup service reads at every boot:

KEYMAP=de

The layouts are the .map.gz files under /usr/share/keymaps, named by layout (fr, de, uk, us, dvorak, colemak, es, it, pl, ru, ...):

$ find /usr/share/keymaps -name '*.map.gz' | sed 's|.*/||; s|\.map\.gz||' | sort | column
Note: This is only the console. Graphical sessions have their own setting: input * xkb_layout fr in Sway, setxkbmap fr under X11.

Font

Console fonts are in /usr/share/consolefonts. Try one with setfont:

$ setfont -d                             # the default font at double size (HiDPI screens)
$ setfont lat9w-16
$ setfont                                # back to the default

and make it permanent with FONT= in /etc/vconsole.conf:

KEYMAP=de
FONT=lat9w-16

Login prompt

Only the first console has a login prompt (getty-tty1). For a login on the second one as well, copy the service:

$ sed 's/tty1/tty2/g' /etc/dinit.d/getty-tty1 | sudo tee /etc/dinit.d/getty-tty2
$ sudo dinitctl enable getty-tty2

Automatic login

To log a user in on tty1 without a password (only on a computer nobody else can touch), add --autologin alex after agetty in /etc/dinit.d/getty-tty1:

command = /usr/bin/agetty --autologin alex tty1 38400 linux

Serial console

Add console=tty0 console=ttyS0,115200 to the kernel command line for boot messages on the serial port, and a getty for it:

$ sed 's/tty1 38400 linux/ttyS0 115200 vt100/; s/tty1/ttyS0/g' /etc/dinit.d/getty-tty1 | sudo tee /etc/dinit.d/getty-ttyS0
$ sudo dinitctl enable getty-ttyS0

Scrolling and blanking

Shift+PageUp scrolling is not available in recent kernels. Use less or a terminal multiplexer (sudo get install tmux). The screen goes blank after 10 minutes without input; turn that off with setterm --blank 0, or consoleblank=0 on the kernel command line.
