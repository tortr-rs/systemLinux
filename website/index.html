systemLinux v0.3 — Hard Drive Installation Handbook

This handbook covers migrating systemLinux from its volatile live memory environment (/dev/ram0) down to a permanent internal disk (e.g., an internal NVMe or SATA SSD). Run every command as root from the live system. The disk you pick is erased.

01

Boot the live systemLinux RAM-disk, identify the target internal disk, and create a GPT layout with a 512MB EFI System Partition and a root partition. The commands below assume an NVMe drive (/dev/nvme0n1); adjust the names for SATA (/dev/sda1, /dev/sda2).

# list block devices, confirm the target disk
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT

# destructive: wipes /dev/nvme0n1 and creates p1 (ESP) + p2 (root)
sfdisk /dev/nvme0n1 <<'EOF'
label: gpt
,512M,U
,,L
EOF
02

Format the storage partitions.

mkfs.vfat -F32 /dev/nvme0n1p1
mkfs.ext4 /dev/nvme0n1p2
03

Mount the root partition on a scratch path, then mount the EFI partition inside the target layout.

mkdir -p /mnt/target
mount /dev/nvme0n1p2 /mnt/target

mkdir -p /mnt/target/boot/efi
mount /dev/nvme0n1p1 /mnt/target/boot/efi
04

Deep-copy the live running userland onto the disk. -x keeps the copy on one filesystem so the virtual filesystems stay out; then recreate their mount points empty.

cp -ax / /mnt/target/

mkdir -p /mnt/target/proc /mnt/target/sys /mnt/target/dev /mnt/target/run /mnt/target/tmp
chmod 1777 /mnt/target/tmp
05

Write the filesystem table.

cat << 'EOF' > /mnt/target/etc/fstab
/dev/nvme0n1p2  /         ext4  errors=remount-ro  0  1
/dev/nvme0n1p1  /boot/efi vfat  defaults           0  2
EOF
06

Write the bare-metal GRUB configuration. The kernel has no initramfs, so the root partition path must be given directly for it to mount.

mkdir -p /mnt/target/boot/grub
cat << 'EOF' > /mnt/target/boot/grub/grub.cfg
set default=0
set timeout=3

menuentry "systemLinux v0.3 (Bare Metal)" {
    linux /boot/vmlinuz root=/dev/nvme0n1p2 rw console=tty0 init=/sbin/systemL quiet loglevel=3
    # if nvme0n1p2 fails to mount, switch to root=PARTUUID=<your-root-partuuid>
}
EOF
07

Place the monolithic kernel on the permanent boot track and deploy GRUB to the drive.

cp /boot/vmlinuz /mnt/target/boot/vmlinuz

grub-install --target=x86_64-efi --efi-directory=/mnt/target/boot/efi \
  --boot-directory=/mnt/target/boot --removable
08

Unmount and reboot into the permanent installation.

umount -R /mnt/target
reboot # remove the installation media on restart
