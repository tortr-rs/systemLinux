systemLinux

A small x86_64 GNU/Linux distribution: dinit instead of systemd, the newest kernel, and software built from source with get, from a ports tree of over a thousand recipes. Nobody owns it and nobody profits from it.

Download 0.2.5Read the handbookBrowse packages
dinit, no systemdServices are small files in /etc/dinit.d. systemd is not there at all; eudev manages devices.
Built from sourceget install NAME builds a package and everything it needs from the ports tree, and get remove takes it out again cleanly.
One set of filesPackages install into /usr like the base system, and get knows who owns every file.
Official builds when it makes senseBrowsers, IDEs and toolchains that take hours to compile come as -bin ports of the upstream release.
Newest kernelUbuntu's newest generic kernel with all its driver modules.
BIOS and UEFIOne hybrid ISO; install with the handbook or systemlinux-install.

Quick start

get install sway          # build sway and everything it needs
get install firefox       # Mozilla's official build
get search editor         # search the ports tree
get remove sway           # uninstall exactly what was installed
