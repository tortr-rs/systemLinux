systemLinux

A small x86_64 GNU/Linux distribution that nobody owns and nobody profits from. The latest Ubuntu kernel, dinit (no systemd), GNU userland. Boots on legacy BIOS and UEFI. The live ISO is installer media only. Software is built from source tarballs with get.
