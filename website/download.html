Download

One live ISO you can write to a USB stick or drop onto a Ventoy drive. Boot in UEFI or legacy BIOS mode.

systemLinux

Boots to a root shell on the console. Install it by hand with the handbook, or run systemlinux-install. The ISO is about 400 MB and needs 3 GB of RAM (4 GB or more for copy to RAM).

systemLinux-0.2.2-x86_64.iso

SHA-256
systemLinux-0.2.2-x86_64.iso.sha256 (all checksums: SHA256SUMS). Check it before you trust a copy from anywhere else.

Check your download with sha256sum systemLinux-0.2.2-x86_64.iso against the checksum on the releases page. Older versions are on the releases page; the source is on GitHub.

Ventoy: copy the ISO onto the stick. Older systemLinux ISOs on the same stick are fine: each ISO only boots its own system. If it reports an error at boot, write the ISO straight to a stick instead.
