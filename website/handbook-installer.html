systemlinux-install performs chapters 5 to 10 for you. It is a plain terminal program: it asks its questions, shows what it will erase, and does nothing until you type yes.

# systemlinux-install

Connect to the network first (chapter 4): it downloads the stage. Without a network, bring the stage on a stick and give it with --stage FILE.

The questions

  1. [d]isk or [p]artition: d erases a whole disk and creates the recommended layout; p formats one partition you freed up and leaves the rest of the disk alone (dual-boot).
  2. The disk or partition, from the list it shows.
  3. Computer name, username, time zone (e.g. Europe/Paris) and console keymap (e.g. fr).
  4. Your password, and whether root gets the same one.
  5. Encrypt with LUKS? (whole-disk installs) and the passphrase.

What it does

  1. Checks the stage can be downloaded, before touching any disk.
  2. Partitions (GPT: BIOS boot, 1 GiB EFI System Partition as /boot, root) and formats; encrypts the root partition if asked.
  3. Downloads the stage onto the new root filesystem, checks its SHA-256 and extracts it.
  4. Moves the kernel and initramfs to /boot/systemlinux.
  5. Writes /etc/fstab, the hostname, /etc/hosts, the time zone, LANG=C.UTF-8 and the keymap.
  6. Creates your user in the groups wheel, video, audio, input and networkmanager, with sudo, and sets root's password.
  7. Installs GRUB: for both UEFI and BIOS on a whole disk; on a partition, only for the firmware you booted with, and on UEFI as its own entry in the existing EFI System Partition. Then runs systemlinux-grubcfg.

Options

Every question can be answered on the command line, for scripted installations:

# systemlinux-install --disk /dev/sda --host laptop --user alex --tz Europe/Paris --keymap fr --luks
Option
--disk DISKerase and use this whole disk
--partition PARTformat and use this one partition (dual-boot)
--esp PARTthe existing EFI System Partition to use with --partition (found automatically when there is one)
--stage FILEa stage tarball you already have, instead of downloading it
--host, --user, --tz, --keymapthe settings it would ask for
--luksencrypt the root partition (whole disk only)
--yesdo not ask for confirmation

Passwords are always asked: they never appear on a command line.
