fstab

/etc/fstab lists the filesystems mounted at boot. Refer to them by UUID, which never changes, unlike /dev/sda3:

# blkid /dev/sda2 /dev/sda3
/dev/sda2: LABEL="BOOT" UUID="4C1A-0B2E" TYPE="vfat" ...
/dev/sda3: LABEL="systemLinux" UUID="9f2c1d6e-..." TYPE="ext4" ...

Write the file with your UUIDs (nano /mnt/etc/fstab):

# <filesystem>                            <mount point>  <type>  <options>         <dump> <pass>
UUID=9f2c1d6e-0000-0000-0000-000000000000  /              ext4    defaults,noatime  0      1
UUID=4C1A-0B2E                             /boot          vfat    umask=0077        0      2
  • Encrypted root: /dev/mapper/root / ext4 defaults,noatime 0 1 (the initramfs already opened and mounted it; this line is for tools that read fstab).
  • Dual-boot on UEFI: the EFI System Partition goes to /boot/efi instead of /boot.
  • A separate /home: UUID=... /home ext4 defaults,noatime 0 2.
  • A swap partition: UUID=... none swap defaults 0 0.

A swap file (optional)

# dd if=/dev/zero of=/mnt/swapfile bs=1M count=4096 status=progress     # 4 GB
# chmod 600 /mnt/swapfile && mkswap /mnt/swapfile
# echo '/swapfile  none  swap  defaults  0 0' >> /mnt/etc/fstab

Entering the new system

From here on you work inside the new system with chroot, so that commands and files are the new system's own. It needs the kernel's virtual filesystems:

# mount --rbind /dev /mnt/dev && mount --make-rslave /mnt/dev
# mount --rbind /sys /mnt/sys && mount --make-rslave /mnt/sys
# mount -t proc proc /mnt/proc
# cp -L /etc/resolv.conf /mnt/etc/resolv.conf        # DNS inside the chroot
# chroot /mnt /bin/bash
# source /etc/profile
# export PS1="(chroot) $PS1"

--make-rslave keeps the unmounting at the end from also unmounting the live system's own /dev and /sys. Every command below runs inside the chroot.

Hostname

# echo mycomputer > /etc/hostname
# printf '127.0.0.1\tlocalhost\n::1\t\tlocalhost\n127.0.1.1\tmycomputer\n' > /etc/hosts

Time zone and clock

# ls /usr/share/zoneinfo/                   # regions; then e.g. ls /usr/share/zoneinfo/Europe
# ln -sf /usr/share/zoneinfo/Europe/Paris /etc/localtime
# hwclock --systohc --utc                    # keep the hardware clock in UTC

Dual-booting with Windows, which keeps the hardware clock in local time: either tell Windows to use UTC (search for RealTimeIsUniversal) or accept that one of the two shows the wrong time after switching.

Language

# echo LANG=C.UTF-8 > /etc/locale.conf

C.UTF-8 is English with full Unicode support and works without generating anything.

Keyboard

# echo KEYMAP=fr > /etc/vconsole.conf

dinit's system-identity service loads it at every boot. A FONT= line sets a console font the same way, if you install one.

Services

The stage starts what a system needs (devices, filesystems, D-Bus, NetworkManager, a login on tty1). Add others now or later with dinitctl enable; see Services with dinit.
