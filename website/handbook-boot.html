Starting from the stick

Plug the stick in and turn the computer on while pressing its boot menu key: usually F12, also F11, F10, F8 or Esc. Pick the stick. If it is listed twice, the UEFI entry installs a UEFI system and the other one a legacy BIOS system; choose UEFI on any computer from the last ten years.

If the stick is not listed: turn Secure Boot off and, on older computers, enable USB boot in the firmware settings (usually F2 or Del at power on).

The boot menu

EntryWhat it does
systemLinux 0.2.5The normal live system.
copy to RAMLoads the whole live system into memory first (needs about 2 GB free). You can then pull the stick out, for example to install onto the stick itself.
serial consoleAlso uses the first serial port: for servers and headless virtual machines.
debug shellShows every boot message and stops in a shell just before the system starts. Type exit to continue booting. See Troubleshooting.

Press e on an entry to change its kernel command line for this boot only; Boot options lists what systemLinux understands.

The live system

After a few seconds you are logged in as root on the first console. The live system is a full systemLinux running from the ISO; whatever you change is kept in memory and gone at the next boot. There is one console; to read this Handbook while you work, open it on a phone or another computer, or install over SSH (below).

Keyboard layout

The console starts with a US layout. Load yours:

# loadkeys fr          # or de, uk, es, it, dvorak, ...
# ls /usr/share/keymaps/i386/*/   # every available layout

A bigger font

On a high-resolution screen the console font is tiny. setfont -d doubles it.

Check how you booted

# ls /sys/firmware/efi    # exists: booted in UEFI mode; "No such file": legacy BIOS

This matters in chapter 5 and chapter 9.

Remote installation

To install from another computer over SSH, set a root password and start the SSH server:

# passwd
# /usr/bin/sshd
# ip -brief address      # the address to connect to

Then ssh root@ADDRESS from the other computer.
