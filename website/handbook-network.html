You need the network to download the stage. The live system runs NetworkManager.

Wired

An Ethernet cable works by itself: NetworkManager configures it with DHCP as soon as it is plugged in. Check:

# nmcli device status
# ping -c 3 github.com

Wi-Fi

# nmcli device wifi list
# nmcli device wifi connect "NETWORK NAME" password "PASSWORD"

nmtui does the same with menus. A hidden network needs hidden yes at the end of the connect command.

The live ISO carries no firmware. Most wired cards and some Wi-Fi cards work without it; many Wi-Fi cards (Intel, Realtek, Broadcom) need firmware and do not appear in nmcli device. Use Ethernet, or share your phone's connection over USB (USB tethering): it shows up as a wired card.

A static address

# nmcli connection add type ethernet ifname enp1s0 con-name wired \
      ipv4.method manual ipv4.addresses 192.168.1.50/24 ipv4.gateway 192.168.1.1 ipv4.dns 1.1.1.1
# nmcli connection up wired

A proxy

# export https_proxy=http://proxy.example:3128 http_proxy=http://proxy.example:3128

curl and get use these variables.

The clock

Downloads over HTTPS fail with certificate errors when the clock is far off. Check it, and set it if needed (UTC):

# date
# date -u -s "2026-10-17 12:00"
