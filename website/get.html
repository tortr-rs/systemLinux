get

get is a small POSIX sh script: it downloads a source tarball, extracts it, runs ./configure --prefix=… (if there is one), make and make install.

$ get https://ftp.gnu.org/gnu/hello/hello-2.12.tar.gz
$ get -p "$HOME/.local" https://example.org/foo-1.0.tar.xz
$ get -d /tmp/stage -c "--disable-nls" https://example.org/bar-2.0.tgz
$ get --help
  • Formats. .tar.gz, .tgz, .tar.bz2, .tar.xz and .tar. Anything else fails with a clear message.
  • Where it goes. -p DIR sets the prefix (default /usr/local); -d DIR stages the install under DESTDIR.
  • Clean. It builds in a temporary directory and removes it afterwards (-k keeps it).
  • Tools. Uses curl or wget, tar and make.

Ports

Besides plain URLs, get reads a ports tree: get category/name (or just get name) installs a package and its requires first. The tree has about 790 recipes covering core utilities, networking tools, compilers and toolchains, editors, shells, libraries, X11 and Wayland, media, security, databases, games and developer tools. Newer recipes carry a verified sha256; tools/ports-check.sh checks the whole tree in CI.

get sys-app/dinit
get net/iperf3
get --sync
