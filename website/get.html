get

get is a Bash script: it can download a source tarball or build a package from a ports recipe. It extracts and builds the source, then installs it under the prefix you choose.

$ get https://ftp.gnu.org/gnu/hello/hello-2.12.tar.gz
$ get -p "$HOME/.local" https://example.org/foo-1.0.tar.xz
$ get -d /tmp/stage -c "--disable-nls" https://example.org/bar-2.0.tgz
$ get --help
  • Formats. .tar.gz, .tgz, .tar.bz2, .tbz2, .tar.xz, .txz and .tar.
  • Where it goes. -p DIR sets the prefix (default /usr/local); -d DIR stages the install under DESTDIR.
  • Clean. It builds in a temporary directory and removes it afterwards (-k keeps it).
  • Tools. Uses curl or wget, tar and make; the selected recipe can also require CMake or Meson.

Install from a recipe

Use a port name such as get dev-apps/cmake to download and build its recipe. The install prefix defaults to /usr/local, which normally needs root: sudo get dev-apps/cmake. Use get -p "$HOME/.local" dev-apps/cmake to install under your home directory, or get -d /tmp/stage dev-apps/cmake to stage files under /tmp/stage without installing them into the live filesystem.

On a minimal installation, first add the build profiles with sudo get --profile build-toolchain and sudo get --profile common-build-deps. Read the recipe guide for how to create recipes, add dependencies, and understand the build and install steps.
