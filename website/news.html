What's new in 0.2.2

  • systemd is gone. dinit is the only init system and eudev the device manager. Services are small files in /etc/dinit.d/; use dinitctl and the usual reboot, poweroff, halt.
  • Latest Ubuntu kernel. Linux 7.3.0 from Ubuntu 26.10 with its full module tree, so network, graphics and sound drivers load on the running system.
  • About 440 more ports (now 792): libraries, X11 and Wayland tools, networking, media, security, databases and games, each with a verified checksum.
  • Legacy BIOS boot. The ISO is a hybrid BIOS+UEFI image, and systemlinux-install installs in either mode (GPT with a BIOS boot partition and an EFI partition).
  • Boot fixes. The live medium is found behind ATA/IDE, SCSI, VMware and Hyper-V controllers; copy-to-RAM works; CI boots the ISO through GRUB in QEMU in both BIOS and UEFI mode.
  • Live boot fix. The ISO no longer stops with "could not find the live medium": the initramfs now carries and loads the storage and filesystem kernel modules.
  • goget is now get. A small POSIX sh script: get URL downloads a source tarball, builds it and installs it. goget and its image updater are gone.
  • Minimal installer-only ISO. The live image is the kernel plus the bare minimum to run systemlinux-install. No desktop, no extra daemons, no compilers.
  • Build stack on demand. After installing, get --profile build-toolchain (and common-build-deps, lang-runtimes) adds what you need; validate-build-ready checks it.

Breaking changes and the full list are in the changelog.
