systemLinux 0.2.5 released

2026-10-17
  • Desktop sessions without elogind. Your runtime directory (XDG_RUNTIME_DIR) is made when you log in, and a per-user dinit starts the session D-Bus, PipeWire and WirePlumber. Put exec dinit in your sway or i3 config.
  • linux-firmware: kernel.org's firmware for Wi-Fi cards, GPUs and Bluetooth, compressed, with sudo get install linux-firmware.
  • New users are in the video, audio and input groups, so seatd, sound and input devices work.

systemLinux 0.2.4 released

2026-10-15
  • 253 Python modules from PyPI (requests, httpx, rich, click, pydantic, numpy, pandas, pillow, ...) and 226 Perl modules from CPAN (Moose, Mojolicious, DBI, DateTime, LWP, ...), each with its dependencies.

The ports tree now has 1619 packages: browse them.

systemLinux 0.2.3 released

2026-10-15
  • One package world. get installs into /usr and /etc like the base system, and the image records its own packages, so get knows which package owns every file. A port replaces the base package of the same name in place; anything else that would overwrite a system file is refused. Your existing configuration in /etc is kept.
  • 214 -bin ports. Official upstream builds of software that takes hours to compile: Firefox, Thunderbird, Brave, VS Code, VSCodium, Zed, Blender, GIMP, Krita, Obsidian, Node, Zig, a JDK, LLVM, Docker, Tailscale, Ollama and many command line tools. Servers come with dinit services.
  • More desktop ports. The greetd login manager with tuigreet, PipeWire and WirePlumber, swaylock, swayidle, grim, mako, dunst, i3lock, bspwm and more, plus Rust 1.99, helix, zellij, yazi, lazygit and gh.
  • Packaging guide. How to write, test and submit a port.
  • New website with a searchable package list.

The full list is in the changelog.

systemLinux 0.2.2 released

2026-10-14
  • systemd is gone. dinit is the only init system and eudev the device manager. Services are small files in /etc/dinit.d/; use dinitctl and the usual reboot, poweroff, halt.
  • Latest Ubuntu kernel. Linux 7.3.0 from Ubuntu 26.10 with its full module tree, so network, graphics and sound drivers load on the running system.
  • About 440 more ports (now 792): libraries, X11 and Wayland tools, networking, media, security, databases and games, each with a verified checksum.
  • Legacy BIOS boot. The ISO is a hybrid BIOS+UEFI image, and systemlinux-install installs in either mode (GPT with a BIOS boot partition and an EFI partition).
  • Boot fixes. The live medium is found behind ATA/IDE, SCSI, VMware and Hyper-V controllers; copy-to-RAM works; CI boots the ISO through GRUB in QEMU in both BIOS and UEFI mode.
  • Live boot fix. The ISO no longer stops with "could not find the live medium": the initramfs now carries and loads the storage and filesystem kernel modules.
  • goget is now get. A small POSIX sh script: get URL downloads a source tarball, builds it and installs it. goget and its image updater are gone.
  • Minimal installer-only ISO. The live image is the kernel plus the bare minimum to run systemlinux-install. No desktop, no extra daemons, no compilers.
  • Build stack on demand. After installing, get --profile build-toolchain (and common-build-deps, lang-runtimes) adds what you need; validate-build-ready checks it.

Breaking changes and the full list are in the changelog.
