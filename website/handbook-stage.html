The stage is the whole systemLinux system in one archive: the base system, compilers and build tools, the ports tree, the kernel and its modules, the initramfs and the documentation. Installing systemLinux is extracting it onto your root filesystem. (Gentoo calls its archive a stage3; systemLinux has only one stage.)

Download it

Download onto the new root filesystem itself, so a small amount of RAM is no problem:

# cd /mnt
# curl -LO https://github.com/tortr-rs/systemLinux/releases/download/v0.2.5/systemLinux-stage-0.2.5-x86_64.tar.xz
# curl -LO https://github.com/tortr-rs/systemLinux/releases/download/v0.2.5/systemLinux-stage-0.2.5-x86_64.tar.xz.sha256

Use the stage of the same version as the live ISO (cat /usr/share/systemlinux/image-version). If you brought it on a USB stick, mount the stick (mount /dev/sdb1 /media) and copy it to /mnt.

Check it

# sha256sum -c systemLinux-stage-0.2.5-x86_64.tar.xz.sha256
systemLinux-stage-0.2.5-x86_64.tar.xz: OK

Extract it

# tar --numeric-owner --xattrs --xattrs-include='*' --acls -xpf systemLinux-stage-0.2.5-x86_64.tar.xz -C /mnt
# rm systemLinux-stage-0.2.5-x86_64.tar.xz*
OptionWhy
-pKeep every file's permissions, including the setuid bits of su, sudo and passwd.
--numeric-ownerKeep owners as numbers. The live system's user names may map to different numbers.
--xattrs --xattrs-include='*'Keep extended attributes, such as the capabilities that let ping work without root.
--aclsKeep access control lists.

This takes a few minutes. Afterwards /mnt looks like any Linux system: ls /mnt.

Mount the boot partition

The stage put the kernel and the initramfs in /mnt/boot. Move them aside, mount the boot partition over /mnt/boot, and put them in /boot/systemlinux on it:

# mv /mnt/boot/vmlinuz /mnt/boot/initrd.img /mnt/root/
# mount /dev/sda2 /mnt/boot
# mkdir -p /mnt/boot/systemlinux
# mv /mnt/root/vmlinuz /mnt/root/initrd.img /mnt/boot/systemlinux/

Dual-boot on UEFI (no boot partition of your own): leave the kernel in /mnt/boot, move it into /mnt/boot/systemlinux/ there, and mount the existing EFI System Partition at /mnt/boot/efi instead:

# mkdir -p /mnt/boot/systemlinux /mnt/boot/efi
# mv /mnt/boot/vmlinuz /mnt/boot/initrd.img /mnt/boot/systemlinux/
# mount /dev/nvme0n1p1 /mnt/boot/efi       # your existing EFI System Partition

A separate /home partition: mount /dev/sda4 /mnt/home now.
