systemLinux boots with GRUB. Its files go to /boot/systemlinux/grub, next to the kernels, so they never collide with another system's bootloader on a shared EFI System Partition. All commands run inside the chroot.

UEFI

# grub-install --target=x86_64-efi --efi-directory=/boot --boot-directory=/boot/systemlinux --bootloader-id=systemLinux

This copies GRUB to /boot/EFI/systemLinux/grubx64.efi and adds a systemLinux entry to the firmware's boot menu. Some firmware forgets entries it did not make itself; also install GRUB at the fallback path, which every UEFI firmware tries:

# grub-install --target=x86_64-efi --efi-directory=/boot --boot-directory=/boot/systemlinux --removable

Dual-boot: use --efi-directory=/boot/efi (where you mounted the existing EFI System Partition) and skip --removable: the fallback path may belong to the other system.

If grub-install says it cannot set the boot entry (efibootmgr errors), you booted the live system in BIOS mode or the firmware refuses: the --removable copy still boots.

Legacy BIOS

# grub-install --target=i386-pc --boot-directory=/boot/systemlinux /dev/sda

Note: the disk (/dev/sda), not a partition. GRUB writes its code to the disk's first sector and to the 1 MiB BIOS boot partition. Running both this and the UEFI commands makes the disk boot on either kind of computer.

The menu

# systemlinux-grubcfg
systemlinux-grubcfg: /boot/systemlinux/grub/grub.cfg (root=UUID=9f2c... on /dev/sda3, kernels on /dev/sda2)

systemlinux-grubcfg looks at what is mounted (where /boot is, which filesystem is root, whether root is encrypted) and writes a menu with one entry per kernel in /boot/systemlinux, and a debug entry for the newest. Run it again whenever you add or remove a kernel or change the root filesystem. Have a look at the result:

# cat /boot/systemlinux/grub/grub.cfg

A typical entry:

menuentry "systemLinux" {
    linux /systemlinux/vmlinuz root=UUID=9f2c... rootfstype=ext4 quiet loglevel=3
    initrd /systemlinux/initrd.img
}

Kernel options of your own (for example mitigations=off or i915.enable_psr=0) go after loglevel=3; edit the file, and redo it if you run systemlinux-grubcfg again.

Other systems in the menu

GRUB's menu only lists systemLinux. To start another system, use the firmware's boot menu (F12), or add an entry to grub.cfg. For Windows on UEFI:

menuentry "Windows" {
    search --no-floppy --file --set=root /EFI/Microsoft/Boot/bootmgfw.efi
    chainloader /EFI/Microsoft/Boot/bootmgfw.efi
}
