The root password

# passwd

Your user

# useradd -m -G wheel,video,audio,input -s /bin/bash YOURNAME
# passwd YOURNAME
GroupGives
wheelsudo and su (see below)
videothe GPU, and seatd (Wayland compositors)
audiosound cards
inputkeyboards, mice and touchpads (libinput)
networkmanagerchanging network connections without sudo (create it first: groupadd -r networkmanager)

Allow the wheel group to use sudo:

# echo '%wheel ALL=(ALL:ALL) ALL' > /etc/sudoers.d/10_wheel
# chmod 440 /etc/sudoers.d/10_wheel
# visudo -c

Or do all of this in one go: systemlinux-provision --user YOURNAME / creates the account in those groups, asks for its password twice and sets up sudo.

Leaving and rebooting

# exit                     # leave the chroot
# umount -R /mnt
# cryptsetup close root      # only if you encrypted the root partition
# reboot

Take the stick out when the screen goes black.

The first boot

GRUB shows its menu for three seconds. With an encrypted root, the initramfs asks for the passphrase. Then dinit starts the system and the console asks you to log in. Log in as yourself and check:

$ sudo whoami
root
$ dinitctl list                 # the running services
$ nmcli device status           # the network

Your system is installed. Next:

  • Firmware, graphics and sound: sudo get install linux-firmware first if your Wi-Fi or GPU needs it.
  • Installing software with get.
  • A desktop: sway or i3.

If it does not boot, see Troubleshooting and recovery.
