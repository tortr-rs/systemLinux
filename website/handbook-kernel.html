The stage comes with a kernel ready to boot: there is nothing to compile. This chapter explains what is there, so you can change it.

What the stage installed

FileWhat it is
/boot/systemlinux/vmlinuzThe kernel: Ubuntu's newest generic kernel, which supports almost all x86_64 hardware.
/usr/lib/modules/VERSION/Its drivers, as modules. eudev loads the ones your hardware needs at boot.
/boot/systemlinux/initrd.imgThe initramfs: a small system the kernel runs first to find and mount your root filesystem.
# ls /usr/lib/modules/          # the kernel version

The initramfs

The kernel cannot mount your root filesystem by itself: the disk controller and filesystem drivers are modules on that very filesystem. The initramfs contains busybox, cryptsetup, the storage and filesystem modules, and one script, /init, which:

  1. loads the drivers for the disk controllers it finds;
  2. waits for the root filesystem named by root= on the kernel command line;
  3. if systemlinux.luks= is given, asks for the passphrase and opens the partition as /dev/mapper/root;
  4. mounts the root filesystem and starts /usr/bin/dinit on it.

The same initramfs boots the live ISO. Every option it understands is in Boot options. You do not need to rebuild it after installing: it is not tied to your machine.

Firmware

Many devices (Wi-Fi cards, AMD and Intel graphics, Bluetooth) need firmware files the kernel loads from /lib/firmware. The stage has none, to keep it small. Install them after the first boot, when you have a network:

# get install linux-firmware

That is kernel.org's firmware collection, about 1 GB, compressed. Reboot afterwards. If your Wi-Fi card needs firmware, connect with a cable or USB tethering for this step.

Your own kernel

A linux port that builds the kernel.org kernel (with a configuration that, like Arch's, supports any x86_64 machine) is planned. A kernel you build yourself works as long as you install it as /boot/systemlinux/vmlinuz-VERSION, put its modules in /usr/lib/modules/VERSION, give it an initramfs as /boot/systemlinux/initrd.img-VERSION and run systemlinux-grubcfg: every vmlinuz* in /boot/systemlinux gets its own menu entry.
